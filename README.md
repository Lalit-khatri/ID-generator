# 🆔 ID Generator

A fast, lightweight, and customizable tool for generating unique identifiers. 

## ✨ Features
* **Customizable Formats:** Generate alphanumeric strings, numeric codes, or standard UUIDs.
* **Prefixes & Suffixes:** Easily attach custom tags to your generated IDs (e.g., `USER-12345`).
* **High Performance:** Optimized to generate multiple unique IDs quickly without collisions.
* **Easy to Use:** Simple setup and clear functions for seamless integration into your workflow.
